# Workify_Web
A full-stack job portal web application with a React frontend and a Java Spring Boot backend, using MongoDB for data storage. Features include job posting, job search, filtering, user authentication, and an admin dashboard. Designed for employers to post jobs and for job seekers to find and apply for jobs in Sri Lanka,
